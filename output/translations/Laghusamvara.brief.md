# Translation Brief: Laghusaṃvaratantra (Herukābhidhāna / Cakrasaṃvaratantra)

## 1. Target language

English

## 2. Register & style

Favour scholarly English prose in the register of modern Cakrasaṃvara studies (Alexis Sanderson, David Gray); retain Sanskrit technical terms in IAST throughout, glossing each on first occurrence in parentheses; use Latinate syntax where it mirrors the Sanskrit, but avoid archaism for its own sake; preserve the verse/prose distinction (śloka pairs read as rhythmic couplets; prose passages as continuous sentences); do not smooth over deliberate obscurity in the antinomian and secret-signs passages — flag with a translator's bracket rather than normalise.

## 6. Notes on the references and the source text itself

**No user-supplied references are present.** The `references/` folder contains only a README. The terminology table above is derived from standard scholarly usage in Cakrasaṃvara studies (Sanderson, Gray) and from direct reading of the source text. The translator agent must use these choices consistently and flag any term not covered here for the user to decide.

**Source text — composite critical edition (`sources/Laghusamvara.txt`):**

The file is a single IAST text stitching two distinct editorial layers:

- *Sarnath edition* (paṭalas 1.1–1.15 first set, and paṭalas 4 onward where marked `%% Paṭala N based on Sarnath edition` or `% Paṭala N based on Sarnath edition`): based on Pandey 2002 (CIHTS Rare Buddhist Texts Series 26), which includes the Bhavabhaṭṭa commentary (not reproduced here).
- *Sanderson edition* (from line 40 onward within paṭala 1, and subsequent Sanderson-edited paṭalas): based on Baroda MS no. 13290; edited in A. Sanderson, "The Śaiva sources of the Buddhist Tantras of Śaṃvara," unpublished handouts 2–3, Trinity Term 1998. This portion is heavily cross-referenced against the Jayadrathayāmala (YoSa).

**Editorial sigla in the file — do not translate, treat as apparatus:**

| Siglum | Meaning |
|---|---|
| `%% …` | Editor header or source note (Pandey/Sanderson identification, MS reference, handout number). Skip entirely in translation. |
| `% …` | Cross-reference line: parallel passage in YoSa, Abhidhānottaratantra, etc. Preserve in apparatus notes but do not render as text. |
| `*word(em. ed.; X)` | Editorial emendation: read *word*, MS reads X. Note in a translator's footnote-bracket, e.g. "[em. ed.]". |
| `[word]` | Editorial addition (conjecture or supplied text). Retain in translation but note with brackets or a footnote marker. |
| `Cf. SaTaTaSa §N; GuSaTa N.N` | Parallel citation after a verse. Apparatus note only; do not translate. |
| `iti śrīherukābhidhāne … paṭalaḥ …` | Chapter colophon. Translate as a section heading, e.g.: *"Here ends the [N]th chapter of the Śrīherukābhidhāna, [chapter name]."* |
| `<word>` | Angle-bracket addition (minor scribal supply). Translate the word; note angle brackets are the editor's supply. |
| `+` | Sandhi dissolution marker (present in a few lines, e.g. 2.9ab). Apply sandhi before translating if running the text through `apply_sandhi.py`; otherwise treat the `+` as a word boundary. |

**Text structure:**
- Predominantly śloka (anuṣṭubh) verse in half-verse pairs labelled `N.Nab` (pādas a–b) and `N.Ncd` (pādas c–d).
- Paṭalas 4, 7, and several later chapters include extended prose (unlabelled or with prose stanzas).
- Mantra extraction passages (paṭalas 5–8) are highly formulaic, listing ordinal positions in the Sanskrit phoneme grid; translate the framing verse and note that the body encodes the mantra syllables.
- The chommā/chommaka passages (paṭalas 15, 20, 24, 31) mix Sanskrit verse with Apabhraṃśa/Old Bengali phrases for secret recognition signs; flag these with a note and retain the non-Sanskrit words untranslated.
- Chapter count in this file extends to at least paṭala 35 (*advayakarmakālamṛtyuvañcanavidhi*).

**Recommended focus setting:** `"sanskrit"` (single witness). Use `"equal"` only if Tibetan or other witnesses are added.
